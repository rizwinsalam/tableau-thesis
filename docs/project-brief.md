# Project Brief

## Goal
Design a clean, performant Tableau dashboard for a retail-like sales dataset that highlights KPIs, trends, and drill-downs.

## Users
- Executive: high-level overview and YoY trends
- Analyst: segment/geography/category exploration

## Scope
- 3 dashboards: Executive Overview, Drill-Down Analysis, Data Quality
- Data: synthetic generated CSV (`data/synthetic_sales.csv`)
- Publishing: local (Tableau Desktop) initially

## Success Criteria
- Clear KPI story (Sales, Profit, Margin, Discount)
- Intuitive filters and fast interactions
- Consistent color/typography and responsive layouts
