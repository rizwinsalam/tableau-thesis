# Contributing

Thanks for your interest! For small fixes, feel free to open a PR.

## Workflow
1. Fork and create a feature branch
2. Make changes and update docs/screenshots if relevant
3. Open a PR with a clear description and before/after screenshots

## Commit Style
Use concise, imperative messages (e.g., "Add KPI cards")

See `CODE_OF_CONDUCT.md`.
